# Modern Defense

Modern Defense is a mobile-first modern military outpost-defense game built with TypeScript, Vite, HTML/CSS, and Canvas.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages

The included GitHub Action deploys the `dist` build automatically from `main`.

If your repository is not named `modern-defense`, update `base` in `vite.config.ts` to match your repository path.
