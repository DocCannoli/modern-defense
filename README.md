# Modern Defense v0.2.0

Modern military outpost-defense playtest for mobile and desktop browsers.

## v0.2.0 gameplay overhaul
- Larger, centered 1600×900 battlefield with longer engagement approaches.
- Doctrine-based enemy formations, spacing, flanking, multi-axis attacks, cover use, and force composition for all 30 factions.
- Terrain cover/concealment features outside the base.
- Fixed one-per-type outpost slots; combat troops deploy to prepared guard positions.
- Fortifications category and gate-routed perimeter.
- Automatic free repair teams and automatic medical recovery without shutting down whole positions.
- Visible selected-position range circles and on-map reload/repair/medical countdowns.
- One-screen landscape gameplay UI with contextual Kingdom Rush-style upgrade popup.
- Improved stylized military silhouettes and labels for structures and units.
- Improved campaign persistence when returning to the main menu.

GitHub Pages deployment uses `.github/workflows/deploy.yml`.
