# Modern Defense v0.4.0

Major tactical rebuild for mobile browsers.

## Highlights
- Five-building architecture: Command Post, Infantry, Air Defense, Motor Pool, Aviation.
- Base-defense, field-defense, and offensive missions share one unit engine.
- Matchup-specific ten-mission campaigns for every faction pairing.
- Faction Points unlock personnel, equipment, vehicles, aviation, specialists, and support.
- Pre-mission customizable loadouts with saveable presets.
- Individual rendered soldiers inside squad-level units.
- Movable squads and tactical orders.
- Full vehicle and aviation units.
- Doctrine-driven enemy groups.
- Recon-controlled effective engagement range.
- CP-based fortification tree.
- Cross-squad medic support.
- Tracers, muzzle flashes, explosions, smoke, craters, burning wrecks and improved silhouettes.
- Browser-generated combat audio and optional speech-synthesis chatter.
- Landscape-first pinch zoom/pan mobile UI.

The project builds with `npm run build` and deploys to GitHub Pages through the existing workflow.
